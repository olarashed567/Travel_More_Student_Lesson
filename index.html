Travel More - Student Lesson

Learn how to build the website one section at a time. Each section has a preview, its HTML, and its CSS.

1. Navigation Bar (Navbar)

What does it do? The navigation bar appears at the top of the page. It contains the website name, links to sections, and a booking button. We use Flexbox to place these items in one row.

Travel More

  • Home
  • Destinations
  • Gallery

HTML code

<nav class="navbar">
    <h1 class="logo">Travel More</h1>
    <ul class="nav-links">
        <li><a href="#home">Home</a></li>
        <li><a href="#destinations">Destinations</a></li>
        <li><a href="#gallery">Gallery</a></li>
        <li><a href="#contact">Contact</a></li>
    </ul>
    <button class="button" type="button">Book Now</button>
</nav>

CSS code

.navbar {
    background-color: #1E3A5F;
    padding: 20px 6%;
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 20px;
}
.logo { color: white; font-size: 26px; font-weight: bold; }
.nav-links { list-style: none; display: flex; gap: 20px; }
.nav-links a { color: white; text-decoration: none; }
.nav-links a:hover { color: #FF8A00; }
.button {
    background-color: #FF8A00;
    color: white;
    border: none;
    padding: 10px 18px;
    border-radius: 5px;
    cursor: pointer;
    font: inherit;
}
Remember: display: flex arranges the navbar items, while justify-content: space-between spreads them across the row.

2. Hero Section

What does it do? This is the main introduction area. It includes a large heading, a short paragraph, a button, and a travel image. Flexbox places the text and image beside each other.

3. CSS Animation

What does it do? CSS animation adds movement to an element. The @keyframes rule describes how the element changes from its starting state to its ending state.

Watch this heading appear!

The heading uses a simple fade-up animation.

CSS code

.hero-content h1 {
    animation: fadeUp 1s ease-in-out;
}

@keyframes fadeUp {
    from {
        opacity: 0;
        transform: translateY(30px);
    }
    to {
        opacity: 1;
        transform: translateY(0);
    }
}
Remember: from is the beginning of the animation and to is the ending. The duration here is 1s.

5. Our Gallery

What does it do? The gallery displays five travel photographs. CSS Grid divides the area into columns. The first image takes two columns to create a larger image.

HTML code

<section class="gallery-section" id="gallery">
    <h2>OUR GALLERY</h2>
    <div class="gallery">
        <img src="https://images.unsplash.com/photo-1500530855697-b586d89ba3ee?auto=format&fit=crop&w=800&q=80" alt="Mountain landscape">
        <img src="https://images.unsplash.com/photo-1501785888041-af3ef285b470?auto=format&fit=crop&w=500&q=80" alt="Lake and mountains">
        <img src="https://images.unsplash.com/photo-1516483638261-f4dbaf036963?auto=format&fit=crop&w=500&q=80" alt="Coastal village">
        <img src="https://images.unsplash.com/photo-1470770841072-f978cf4d019e?auto=format&fit=crop&w=500&q=80" alt="Lake view">

CSS code

.gallery-section { padding: 55px 6%; text-align: center; }
.gallery {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 14px;
}
.gallery img {
    width: 100%;
    height: 190px;
    object-fit: cover;
    border-radius: 8px;
}
.gallery img:first-child { grid-column: span 2; }
Remember: grid-template-columns: repeat(3, 1fr) creates three equal columns. object-fit: cover fills the image box without stretching it.

6. Responsive Design (Media Queries)

What does it do? Media queries change the layout depending on screen width. On smaller screens, the hero becomes vertical, the gallery uses fewer columns, and the navbar stacks.

CSS code

/* Tablet and small screens */
@media (max-width: 768px) {
    .navbar { flex-direction: column; gap: 15px; }
    .nav-links { flex-wrap: wrap; justify-content: center; }
    .hero { flex-direction: column; text-align: center; }
    .hero-content, .hero-image { flex: 1 1 300px; width: 100%; }
    .gallery { grid-template-columns: repeat(2, 1fr); }
}

/* Mobile screens */
@media (max-width: 480px) {
    .gallery { grid-template-columns: 1fr; }
    .gallery img:first-child { grid-column: auto; }
    .cards-container { flex-direction: column; align-items: center; }
    .card { width: 100%; }
}
These media queries use the same class names as the HTML examples above, so you can copy the code directly into your project.
